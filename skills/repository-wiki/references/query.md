# `/wiki query <question> [--save <path>]`

Answer a question from maintained context without changing the wiki by default.

1. Apply maintained-path safety to `wiki/index.md`, record its unfiltered identity before reading, then read it.
2. Select the smallest relevant set of canonical pages. Apply maintained-path safety and record each selected page's unfiltered identity before reading it. Baseline the manifest before reading it as part of source inventory.
3. Inventory the original sources needed to support the answer. For every registered source, reject unsafe paths using the shared symlink and canonical-root rules, require an existing regular file, and compare its unfiltered identity with the manifest. For discovery-workspace transcript evidence, separately baseline the mutable meeting control manifest without registering it as an immutable source; require meeting-level transcription consent to be `granted` or `granted-with-anonymization`, enforce required anonymization, and verify speaker mapping, discovery-use consent, and direct-quotation consent before using or quoting evidence. Treat `unknown` as not granted. Immediately before returning or saving the answer, recheck path safety, regular-file type, and identity for the index, every selected canonical page, the manifest, every source, and every consent control actually used. If any maintained page, manifest, source, or consent state changed, discard the affected answer and restart from the current consistent state; do not return or save a stale or mixed-version answer.
4. Answer with inline citations to verified original sources. For every synthesis across canonical evidence, interpretation, hypothesis, proposal, or decision records, also link each contributing canonical record ID and page anchor so the answer remains connected to reviewed record history; record links supplement rather than replace original-source citations.
5. Separate requests, evidence, interpretations, assumptions, problem hypotheses, proposals, decisions, contradictions, and unknowns when relevant. Preserve every evidence record's type and limitations and a request's original wording and requested solution before discussing any reframing. Preserve every interpretation's author, contributing evidence or evidence IDs, and material alternatives; preserve every assumption's owner, consequence if wrong, risk, and proposed validation; and preserve every decision's chosen action, alternatives considered, rationale, evidence used, unresolved dissent, owner, and date. Use `Unknown` for unavailable values. Keep every problem hypothesis falsifiable with supporting and contradicting evidence listed separately. Do not present source statements as independently verified facts or label them as confirmed findings.
6. If the wiki is insufficient, say so. Prefer ingesting a needed raw source first. When an explicit read-only fallback to an unregistered source is necessary, identify it as unregistered, apply the shared source symlink, containment, secret/ignore, and regular-file checks, and record its unfiltered identity before reading. If it is a discovery-workspace transcript, also apply the mutable-control, transcription, anonymization, speaker, discovery-use, and quotation-consent gates from step 3. Recheck the source path, type, identity, and any consent-control baseline immediately before returning or saving the answer; if any drifted, discard the affected answer and restart from current authorized bytes or require ingestion. Never call an unregistered fallback source verified unless this baseline and final recheck succeeded.
7. With `--save`, resolve the exact output file under the configured wiki root, using `wiki/analysis/` as the default parent directory, and apply the shared path-safety checks. Before generating the answer, record the output file's unfiltered identity or an explicit `absent` sentinel. Immediately before writing, repeat the safety checks and verify that baseline; if the file drifted or an absent path appeared, stop without writing and reconcile the concurrent change. Include the question, actual operation date, original sources, and pages consulted. Do not save without the flag or an explicit request.

Completion condition: the answer addresses the question, fits the available evidence, cites verified original sources, reports provenance gaps, and discloses material uncertainty.
